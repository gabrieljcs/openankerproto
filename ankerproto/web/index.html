This page needs to be served, not opened from disk

  1. Open a terminal in this folder.
  2. Run npm run serve
  3. Open http://127.0.0.1:8080/ in Chrome or Edge.

Browsers refuse to load JavaScript modules over file:// for security reasons. This disables every button on the page, not just demo mode. The same applies if you host the folder without also serving src/.

No device handy? Demo mode is on — press connect to explore the interface with a simulated Anker Prime.

Choose the scan option before pressing Connect. It opens Chrome’s Bluetooth Low Energy picker; it cannot force Chrome to show every device from its internal diagnostic scan.

Device not showing up?

Use Chrome or Edge with Bluetooth enabled. Keep the device nearby, wake it, and disconnect the official phone app. Select Show all nearby devices before pressing Connect to remove this website’s name and service filters.

Chrome on macOS: empty device picker

  1. Open System Settings → Privacy & Security → Bluetooth. If Google Chrome is listed, enable it.
  2. If Chrome is missing from that list, or discovery still fails, paste chrome://bluetooth-internals into Chrome’s address bar.
  3. Select Devices, then Start Scan. Allow Bluetooth access if macOS prompts you.
  4. If you changed permissions, fully quit Chrome with ⌘Q and reopen it. Return here, select Show all nearby devices, and try Connect again.

Chrome’s scan finds devices, but this picker stays empty? That confirms Chrome can scan, but does not confirm your Anker device is among those results. Stop the diagnostic scan and compare the device names with the picker. Look for Anker or your model number; names may differ or be absent. Report whether the picker is completely empty or just missing your device, and include any error from Connection diagnostics.

App-specific BLE devices may not appear in the system’s normal pairing list. This website uses Bluetooth, not Wi-Fi. A device appearing in the phone app does not confirm that your computer can discover it over Bluetooth.

Compatibility varies by model and firmware. Discovering a device does not guarantee protocol support. If the handshake fails after selecting a device, download Connection diagnostics below.

Display theme

Brightness, Intelligent mode, knob direction, clock scheduling, and built-in clock styles have been tested on an A2345. Other controls remain experimental. Apply writes your selected setting to the charger.

Changes how the charger shares power.

Clock display schedule
Repeat on

Uses the charger's local clock. An end time before the start runs overnight.

USB-C port priority

Choose ports to prioritize when power is shared. Unchecked ports remain usable.

Clock time and time zone

Reconnects to the selected charger and sends the computer’s time and time-zone offset. Check your computer’s time zone before syncing. If the hour stays wrong, use Anker Power’s Wi-Fi setup to connect the charger to your network; some firmware relies on Wi-Fi time synchronization.

Clock screensaver

The clock appears when the screen rests, during its display schedule. Choose a screen timeout such as 30 seconds: with “Always on”, the clock will not appear.

Prepare a photo · experimental

Choose a photo, crop it, and prepare a JPEG or PNG with its checksum. Charger image compatibility and output dimensions still need verification.

Photos stay in this browser until you choose Make available to charger.

Local Wi-Fi delivery

Run npm run photo:serve from the web folder. The helper serves only your prepared photo on your local network for 10 minutes. The charger and computer must be on the same network.

About

        

          This is an independent, free and open-source client for Anker's BLE-enabled devices.
          It talks to the device directly from your browser using
          Web Bluetooth. Nothing is sent to any server: there is no backend, no account, and no telemetry.
          The page is static and can be self-hosted.
        

        
How the device connection works

          Security note: the device's BLE link uses AES with a fixed key that
          ships inside the official app, and the initialisation vector is the device serial
          number. Anyone in Bluetooth range may be able to talk to
          the device. See docs/PROTOCOL.md §4.3.
